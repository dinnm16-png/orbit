## Full description
ORBIT is a minimalist physics puzzle about gravity, precision and planning.

Pull back and release to launch a planet toward the gravitational core. Planets
of the same kind merge into bigger ones — and a well-placed shot can set off a
chain reaction. Keep the orbit tidy: if a planet comes to rest outside the ring,
the orbit collapses.

• One-finger controls
• Real-time 2D physics
• 12 planets to discover
• Chain reactions with rising musical notes
• Calm, premium visuals
• Fully offline — no ads, no accounts, no data collection
• Optional planet numbers for color-blind players

Simple to play. Infinite to master.
